# RESIZER
A program that Resizes multiple image files (.jpg, .jpeg, .png, .gif) at once.

# USAGE:
- Download [main.py](https://github.com/wassupmahboi/RESIZER/blob/main/main.py) or the [.exe file](https://github.com/wassupmahboi/RESIZER/releases).
- Put the program in the same folder which contains the images you want to resize.
- **NOTE: THE ABOVE MENTIONED FOLDER CAN HAVE FILES OTHER THAN IMAGES AND/OR SUBFOLDERS WITH IMAGE FILES. YOU CAN CHOOSE TO RESIZE THE IMAGES IN THE SUBFOLDER. IT WILL SKIP ALL OTHER NON-IMAGE FILES**

## USING PYTHON:
- If you are using the [main python file](https://github.com/wassupmahboi/RESIZER/blob/main/main.py), make sure you have the following libraries downloaded:
  1. os
  2. pathlib
  3. pillow **[This is usually the one which is not pre installed with Python]**
- These are not really necessary, needed just to color the text and make it more readable:
  1. termcolor
  2. sys
  3. builtins
- If you don't really care about the color, run this [nocolor.py](https://github.com/wassupmahboi/RESIZER/blob/main/nocolor.py).
- It saves the images in the RESIZED_PHOTOS folder, which is outside the folder the program is in.

## USING THE EXE:
- If you are downloading [RESIZER.exe](https://github.com/wassupmahboi/RESIZER/releases), just click and enjoy :)
- It saves the images in the RESIZED_PHOTOS folder, which is outside the folder the program is in.
